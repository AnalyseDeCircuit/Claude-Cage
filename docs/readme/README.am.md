## በAnthropic ተሰላችተናል

እንደ ተራ ተጠቃሚዎች ከClaude ጋር ለመነጋገር እና ለመተባበር፣ ስለ መለያ እገዳዎች እና የገንዘብ ኪሳራዎች እየተጨነቅን የVPS ምሳሌዎችን፣ የአሳሽ አሻራ መገለጫዎችን እና የአካባቢ ፍተሻዎችን ማዋቀር ሰልችቶናል። እናቀርባለን። **Claude Cage** -**ለመጠቀም ዝግጁ የሆነ የዴስክቶፕ መተግበሪያ፡ የራስዎን የአውታረ መረብ ፕሮክሲ ያዋቅሩ እና የእርስዎን ገለልተኛ አካባቢ፣ የሰዓት ሰቅ፣ ቋንቋ እና የአካባቢ ፍተሻዎችን በአንድ ቦታ ያስተዳድሩ።**

Claude Cage የሊኑክስ ተርሚናልን፣ አሳሽ እና ፋይል አርታዒን በአንድ የዴስክቶፕ መተግበሪያ ውስጥ የሚያጣምር ቀላል ክብደት ያለው የሊኑክስ ቨርቹዋል ማሽን ነው። የእሱ ዋና ባህሪያት የሚከተሉትን ያካትታሉ:

- ከአስተናጋጁ ተነጥለው የአውታረ መረብ ቅንብሮች; Cage ሁሉንም የአውታረ መረብ ትራፊክ በአካባቢያቸው ውስጥ በራሱ የአውታረ መረብ ፕሮክሲ በኩል ያደርሳል
- የሰዓት ሰቅ እና ቋንቋን ጨምሮ ከአስተናጋጁ የተገለሉ የአሳሽ አሻራ ቅንጅቶች ከአውታረ መረቡ ተኪ አይፒ አካባቢ ጋር በራስ ሰር ማመሳሰል
- በClaude የስራ ሂደት ውስጥ ያለው ውህደት፡ የአሳሽ መግባት፣ የመለያ ፍቃድ እና የClaude ኮድ ሂደት
- አብሮገነብ አውታረመረብ እና የመነጠል ፍተሻዎች ወሳኝ ፍተሻዎች ሲቀሩ ወይም ማስረጃው ካልተሟላ የበይነመረብ መዳረሻን ባለበት ያቆማሉ። የማህበረሰብ እና የሶስተኛ ወገን ቼኮች ተጨማሪ የማጣቀሻ መረጃ ይሰጣሉ

## በ Cage ምን ማድረግ ይችላሉ

- **በአንድ መስኮት ውስጥ ይስሩ.** በተርሚናል ውስጥ የClaude ኮድን ያሂዱ፣ በአርታዒው ላይ የተደረጉ ለውጦችን ይገምግሙ እና አገልግሎቶችን አስቀድመው ለማየት እና ለመግባት የCage አሳሹን ይጠቀሙ።
- **የሚያጋሩትን ይቆጣጠሩ።** ነባሪው የስራ ቦታ እና በግልፅ የተከፈቱ የፕሮጀክት ማህደሮች ብቻ ነው የሚጋሩት። የአስተናጋጁ Claude የመግባት ሁኔታ፣ የአሳሽ መገለጫዎች እና የኤስኤስኤች ቁልፎች በራስ ሰር አይመጡም።
- **የአውታረ መረብ ሁኔታዎን ይመልከቱ።** አብሮገነብ የአውታረ መረብ ተኪ አስተዳደር የደንበኝነት ምዝገባዎችን እንድታስመጣ፣ የመጨረሻ ነጥቦችን እንድትመርጥ እና መውጫውን አይፒ እንድታረጋግጥ ያስችልሃል። ወሳኝ ፍተሻዎች እስኪያልፍ ድረስ አካባቢው ከመስመር ውጭ ይቆያል። የአውታረ መረቡ ተኪ የማይገኝ ከሆነ ቀጥታ ግንኙነት ወደ ኋላ መመለስ የለም።
- **በሚቀጥለው ጊዜ ይቀጥሉ.** መሳሪያዎች፣ ፋይሎች እና የመግባት ሁኔታ በምናባዊ ዲስክ ላይ ይቆያሉ። መስኮቱን ሲዘጉ የበስተጀርባ ተግባራት መሮጥ ይችላሉ።

## ፈጣን ጅምር

ይህንን ጥያቄ ወደ AI ወኪልዎ ይላኩ (ኮዴክስ ፣ ዲኤስኤስ ፣ የስራ ጓደኛ - ምናልባት Claude ኮድ 😁 ላይሆን ይችላል)

```markdown
እንድጫን እርዳኝ። https://github.com/Lee-xeo/Claude-Cage እና የCage's network proxy አዋቅር በእኔ የአከባቢ ግጭት የ xxx የመጨረሻ ነጥብ ለመጠቀም።
```

የሚያስፈልግህ አስተማማኝ የአውታረ መረብ ተኪ የመጨረሻ ነጥብ ነው። ይህ ፕሮጀክት ማንኛውንም ተኪ አቅራቢን አያስተዋውቅም። አቅራቢን እራስዎ ማግኘት ይችላሉ፣ ለምሳሌ የጥቁር ስህተት ድህረ ገጽን በመፈለግ።

## ማውረድ እና መጫን

የመጀመሪያው ልቀት ይደግፋል **አፕል ሲሊኮን ማክስ (ኤም-ተከታታይ ቺፕስ) ፣ macOS 14 ወይም ከዚያ በላይ እየሄደ ነው።**. ኢንቴል ማክስ፣ ዊንዶውስ እና ሊኑክስ በአሁኑ ጊዜ ለ Cage ዴስክቶፕ መተግበሪያ የሚደገፉ መድረኮች አይደሉም።

1. ክፈት [GitHub Releases](https://github.com/Lee-xeo/Claude-Cage/releases) እና አፕል ሲሊኮን ይምረጡ `.dmg` በመልቀቂያው ውስጥ የመጫኛ ጥቅል.
2. የመጫኛ ጥቅሉን ይክፈቱ እና ይጎትቱ **Cage** ውስጥ **መተግበሪያዎች**; ከዚያ ከመተግበሪያዎች ያስጀምሩት።
3. የራስዎን የአውታረ መረብ ፕሮክሲ ለማዋቀር፣ አካባቢውን ለመጀመር እና ፕሮጀክት ለመክፈት የውስጠ-መተግበሪያ መመሪያዎችን ይከተሉ።

ጫኚው የስራ ቤንች እና የኔትወርክ ፕሮክሲ ኮርን ያካትታል። ዕለታዊ አጠቃቀም Go፣ Node.js፣ Docker ወይም Clash መጫን አያስፈልገውም። መጀመሪያ ማስጀመር የሊኑክስን ምስል እና የግንባታ መሳሪያዎችን ለማውረድ አሁንም የበይነመረብ ግንኙነት ይፈልጋል። Cage የኔትወርክ ተኪ አገልግሎትም ሆነ የClaude መለያ አይሰጥም።

የአሁኑ ስሪት፡ `0.1.0-alpha.1`. የምንጭ ኮድ፣ ድር ጣቢያ እና የተለቀቁት ይፋዊ ናቸው። ለጫኚ ፊርማ፣ አፕል ኖተራይዜሽን እና የማረጋገጫ ወሰን የእያንዳንዱን ልቀት ማስታወሻ ይመልከቱ። ንጹህ ማሽን መጫን፣ macOS 14 ን በሚያሄዱ አካላዊ Macs ላይ ተኳሃኝነት፣ የእውነተኛ Claude መለያ ፈቃድ እና የሞዴል ጥያቄዎች አሁንም ሙሉ ማረጋገጫ ያስፈልጋቸዋል።

የውስጠ-መተግበሪያ ማሻሻያ ድጋፍ ያላቸው ስሪቶች ከታች በስተግራ ጥግ ላይ ያለውን የዝማኔ ቁጥጥር ያሳያሉ። ዝማኔ ሲገኝ፣ የታች ቀስት መሣሪያ ጫፉ 'አውርድ ዝመናን' ያነባል። እሱን ጠቅ ማድረግ ያውርዳል፣ ያረጋግጣል፣ ይጭናል እና መተግበሪያውን እንደገና ያስጀምራል። አስቀምጥ እና መጀመሪያ ስራዎችን ማስኬድ አቁም. በተመረጠው የአውታረ መረብ ተኪ በኩል ማውረድን ያዘምናል፣ ወደ ቀጥታ ግንኙነት ምንም መመለስ የለም። በራስ ሰር መጫን ከተመሳሳይ አታሚ ፊርማ እና የአፕል ማረጋገጫ ያስፈልገዋል። ተከታይ ስሪቶች የውስጠ-መተግበሪያ ዝማኔዎችን መጠቀም ይችላሉ። ለዝርዝር መረጃ ይመልከቱ [ያሻሽሉ እና ያራግፉ](../getting-started.md#升级与卸载).

## በሶስት ደረጃዎች ይጀምሩ

### 1. የአውታረ መረብ ተኪ ይምረጡ

በመነሻ ገጹ ላይ 'ኔትወርክን እና ፕሮክሲን አዋቅር'፣ በመቀጠል 'ምንጭ አክል' የሚለውን ጠቅ ያድርጉ። የክላሽ/ሚሆሞ YAML ደንበኝነት ምዝገባን ወይም የአካባቢያዊ YAML ፋይል አስመጣ እና በ'Nodes' ስር ያለ የመጨረሻ ነጥብ ምረጥ። ምንም የአውታረ መረብ ተኪ ከሌለ፣ 'ይህንን የደንበኝነት ምዝገባ በአስተናጋጅ አውታረመረብ አውርድ' የሚለውን በግልፅ መምረጥ ወይም የአካባቢ ፋይል በቀጥታ ማስመጣት ይችላሉ። በኋላ፣ የመጨረሻ ነጥቦችን በ'Settings → Network and proxy' ስር ያስተዳድሩ።

### 2. አካባቢውን ይጀምሩ

ወደ የሥራ ቦታው ይመለሱ እና 'ጀምር Cage አካባቢ' ን ጠቅ ያድርጉ። የአስተናጋጁ Git ማዋቀር የደህንነት ጥበቃ ከሚያስፈልገው፣ መተግበሪያው በመጀመሪያ ውጤቱን ያብራራል። 'ጥበቃን አንቃ እና ቀጥል' የሚለውን ጠቅ በማድረግ ይተግብሩ። ተራ ፕሮጀክቶች ላይ ቁርጠኝነት እና መጎተት ምንም ችግር የለውም። Cage ምስሉን ያወርዳል፣ መሳሪያዎችን ይጭናል እና የአውታረ መረብ ፍተሻዎችን ያካሂዳል። የሂደቱን ሂደት በ'ኦፕሬሽን ዝርዝሮች' ይመልከቱ። አንዴ አካባቢው ዝግጁ ከሆነ እና ወሳኝ ቼኮች ካለፉ በመስመር ላይ መስራት ይችላሉ። ቼክ ካልተሳካ፣ ችግሩን ለማስተካከል መመሪያዎቹን ይከተሉ እና እንደገና ይሞክሩ።

### 3. ፕሮጀክት ይክፈቱ እና Claude ያሂዱ

በእርስዎ Mac ላይ አቃፊ ለመምረጥ፣ አዲስ ተርሚናል ለመክፈት እና ለመግባት 'Open Project' ን ጠቅ ያድርጉ `claude`; ከዚያ የራስዎን መለያ በ Cage አሳሽ ውስጥ ፍቀድ። ፕሮጀክት ሳያዘጋጁ በነባሪው የስራ ቦታ መጀመር ይችላሉ። ለሙሉ ደረጃዎች, ይመልከቱ [በመጀመር ላይ](../getting-started.md).

## ከመጠቀምዎ በፊት እነዚህን ገደቦች ይረዱ

- በጋራ ፕሮጀክቶች ውስጥ ያሉ አርትዖቶች እና ስረዛዎች በእርስዎ Mac ላይ ያሉ ፋይሎችን በቀጥታ ይነካሉ። የስሪት መቆጣጠሪያን ወይም ምትኬዎችን ተጠቀም።`.git` እና ሌሎች ሜታዳታ በነባሪነት ተነባቢ-ብቻ ናቸው; Git መፈጸምን በ Mac ላይ ያድርጉ።
- ሁሉም ፕሮጀክቶች መሳሪያዎቹን፣ መለያዎቹን እና የሊኑክስ ፋይል ስርዓቱን ጨምሮ አንድ የ Cage አካባቢን ይጋራሉ። ፕሮጀክቶች አንዱ ከሌላው የተገለሉ አይደሉም።
- እንግዳው በአሁኑ ጊዜ የወል IPv4 TCP በአውታረመረብ ፕሮክሲ በኩል፣ ዲ ኤን ኤስ በተመሳሳይ ፕሮክሲ የተላከ ነው። ይፋዊ UDP፣ IPv6፣ ICMP እና በእንግዳ የተጀመሩ ከአስተናጋጁ ወይም ከአካባቢያዊ አውታረመረብ ጋር ያሉ ግንኙነቶች ታግደዋል። በእነዚህ ችሎታዎች ላይ የተመሰረቱ መሳሪያዎች ላይሰሩ ይችላሉ.
- የአውታረ መረብ ፍተሻዎች የአሁኑን ውቅር እና የናሙና ማስረጃዎችን ያሳያሉ። መለያ የመድረክ ገደቦችን እንደሚያስወግድ ዋስትና ሊሰጡ አይችሉም እና የተሟላ የቨርችዋል ሴኪዩሪቲ ኦዲትን አይተኩም።

ለዝርዝር መረጃ ይመልከቱ [የአውታረ መረብ እና የውሂብ ገደቦች](../getting-started.md#网络与数据边界), [የአውታረ መረብ ቼኮች ንድፍ](../design/network-checks.md) እና [አብሮ የተሰራ የአውታረ መረብ ተኪ ንድፍ](../design/managed-proxy.md).

ለመሠረታዊ ችሎታዎች እና የንድፍ ማመሳከሪያዎች ለሚከተሉት ፕሮጀክቶች ምስጋና ይግባው.

- [agent-vm](https://github.com/sylvinus/agent-vm) የ Cage የላይኛው ተፋሰስ መሠረት።
- [Lima](https://github.com/lima-vm/lima) የሊኑክስ ምናባዊ ማሽን አስተዳደር.
- [gvisor-tap-vsock](https://github.com/containers/gvisor-tap-vsock): ምናባዊ ማሽን አውታረ መረብ.
- [sshocker](https://github.com/lima-vm/sshocker) እና [SFTP](https://github.com/pkg/sftp) በቨርቹዋል ማሽን እና በአስተናጋጅ መካከል የፋይል መጋራት።
- [noVNC](https://github.com/novnc/noVNC) በአሳሹ ውስጥ የርቀት ማሳያ እና መስተጋብር።
- [Mihomo](https://github.com/MetaCubeX/mihomo) አብሮ የተሰራው የአውታረ መረብ ፕሮክሲ ኮር።
- [code-server](https://github.com/coder/code-server): በአሳሽ ላይ የተመሰረተ ኮድ አርታዒ.
- [AIO Sandbox](https://github.com/agent-infra/sandbox) የሥራ አካባቢ እና መስተጋብር ንድፍ ማጣቀሻዎች.
- [claude-switcher](https://github.com/YOURSJEYO/claude-switcher) እና [Claude-Guardian](https://github.com/DUNHKpcc/Claude-Guardian) ለአውታረ መረብ ፍተሻዎች እና የደህንነት ምርመራዎች ማጣቀሻዎች።
